# Web design anti-patterns

What to refuse or rewrite by default on landing pages and promotional UI.

## Layout & structure

| Anti-pattern | Why it fails | Do instead |
|--------------|--------------|------------|
| Dashboard hero (stats + cards + nav + promo) | No single focal point | One composition; hero budget only |
| Inset rounded hero image in a card | Feels like a template widget | Full-bleed / edge-to-edge visual plane |
| Side-by-side “text left, small image right” as default hero | Weak atmosphere; brand-agnostic | Full-bleed visual with typography over/alongside carefully |
| Tiled collage of 4–6 images in hero | Busy; no anchor | One dominant image or scene |
| Every section is a 3-column card grid | Monotony; card addiction | Alternate layout rhythms; cards only for interaction |

## Chrome & decoration

| Anti-pattern | Why it fails | Do instead |
|--------------|--------------|------------|
| Floating badges on imagery (“New”, “50% off” stickers) | Clutter; dated growth-hack look | Integrate message into headline/CTA |
| Pill clusters / tag clouds | Noise without hierarchy | One clear category or none |
| Glassmorphism + glow everywhere | Generic “AI SaaS” sheen | Flat/soft surfaces; one accent |
| Multi-layer drop shadows | Muddy depth | Single subtle shadow or tonal separation |
| Emoji as UI ornament | Unprofessional default | Real iconography or none |

## Color & type clichés

| Anti-pattern | Why it fails | Do instead |
|--------------|--------------|------------|
| Purple → indigo gradients on white | Overused AI aesthetic | Brand-rooted palette; unexpected but restrained |
| Cream + terracotta + display serif combo | Overused “tasteful AI” look | Different temperature/accent story |
| Broadsheet: hairlines, zero radius, dense columns | Costume design | Editorial only if brand is truly newspaper |
| Dark mode with neon accents by default | Atmosphere without meaning | Dark when brand/content needs it |
| Inter/Roboto everywhere on marketing pages | Invisible personality | Distinctive display + readable body |

## Content patterns

| Anti-pattern | Why it fails | Do instead |
|--------------|--------------|------------|
| Social proof, stats, logos, and pricing in first viewport | Hero budget exceeded | Defer to later sections |
| Three primary CTAs | Decision paralysis | One primary, optional text secondary |
| Long feature lists above the fold | Scannability collapse | One promise; details below |
| Lorem / gray box placeholders shipped | Broken trust | Real copy and images or omit |

## Motion

| Anti-pattern | Why it fails | Do instead |
|--------------|--------------|------------|
| Animate every element on scroll | Exhausting; slow | 2–3 intentional moments |
| Autoplaying aggressive video behind text | Readability + a11y issues | Controlled, muted, contrast-safe |
| Hover-only reveals for critical info | Fails touch + keyboard | Always available content |

## Process failures

- Designing chrome before hierarchy
- Adding components to “fill space”
- Matching Dribbble complexity instead of product clarity
- Ignoring the brand test after polish
- Treating accessibility as a later pass
