# Design critique checklist

Use before finishing any landing page, marketing section, or major UI polish.

## First viewport

- [ ] Reads as **one composition**, not a dashboard of widgets
- [ ] **Brand** is hero-level (survives the “remove the nav” test)
- [ ] Only: brand, one headline, one support line, one CTA group, one dominant visual
- [ ] No floating badges, chips, stickers, or labels on hero media
- [ ] No cards in the hero
- [ ] Visual is full-bleed / dominant—not an inset rounded thumbnail

## Hierarchy & content

- [ ] Each section has one job and one clear headline
- [ ] Supporting copy is short; no competing CTAs fighting the primary
- [ ] Related items grouped; groups separated with clear whitespace
- [ ] No clutter clusters (pill rows, stat strips, icon grids as decoration)

## Type & color

- [ ] Type feels intentional (not generic Inter/Roboto/Arial/system unless mandated)
- [ ] Clear scale: display vs body vs label
- [ ] Palette is deliberate; not purple-indigo default or cream+terracotta cliché
- [ ] Accent color used sparingly for action/meaning
- [ ] Text contrast is readable on actual backgrounds

## Imagery & atmosphere

- [ ] Main visual shows product/place/context—not only abstract gradient
- [ ] Background has atmosphere without drowning content
- [ ] Photos/illustrations feel on-brand and high quality

## Motion

- [ ] 2–3 purposeful motions max for visually led pages
- [ ] Motion supports hierarchy (entrance, CTA affordance, section reveal)
- [ ] `prefers-reduced-motion` respected

## Responsive & a11y

- [ ] Mobile first viewport still shows brand + headline + CTA
- [ ] Tap targets adequate; no hover-only critical actions
- [ ] Focus states visible; semantics/heading order sound
- [ ] Meaningful alt text where needed

## Cards & chrome

- [ ] Cards only where interaction needs a container
- [ ] Borders/shadows/radius earn their keep
- [ ] No multi-layer shadow / glow stack for “premium” fake depth

## Final taste pass

- [ ] Could this be mistaken for generic AI UI template? If yes, push direction harder
- [ ] Would a senior designer remove something? Remove it
- [ ] Primary action is obvious within 2 seconds
